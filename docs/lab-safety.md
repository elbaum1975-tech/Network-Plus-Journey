# Lab safety and scope

- Practice only on computers, virtual machines, and networks you own or have explicit permission to test.
- Keep experiments on an isolated virtual network with no bridge to a home, school, or workplace LAN unless the exercise explicitly requires an approved connection.
- Do not scan public IP addresses or other people’s devices. Use the lab addresses and targets you deliberately configured.
- Save a copy of important work before changing network or system settings. A VM snapshot helps roll back a guest but does not replace an independent backup.
- Start only the virtual machines needed for the current exercise. Check available memory and disk space first.
- After a lab, stop temporary services, restore changed settings, and record what you changed.
- Examples in this repository are for learning. Review commands and adapt them to your own environment before use.
